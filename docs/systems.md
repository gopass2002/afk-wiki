# 시스템·경제

가방·상점·경매·길드·출석·미션·콘텐츠 해금 등은 [테이블 인덱스]({{ '/docs/data/tables/' | relative_url }})의 원본 테이블로 연결됩니다. 대표적으로 `bag-*`, `shop-*`, `auction-*`, `guild-*`, `content-unlock`, `event-mission`, `reward-*`가 있습니다.

각 문서의 행·필드가 사실의 경계입니다. 서버 전용 로직, UI에서만 조합되는 표시명, 필드명만으로 확정할 수 없는 게임 규칙은 추측하지 않습니다.
